# NeoNews Smart Tools

Server-local editorial and reader features. **No external AI, no API keys, no data leaving your site.**

## Setup

1. Activate **NeoNews Smart Tools**
2. Open **NewsPulse → Smart Tools**
3. Leave defaults on (all features enabled) or toggle as needed

**Requires for full experience:**
- **Activity tracking** enabled (Core) — for “Recommended for you”
- **Membership** (optional) — weekly digest goes to premium members first

## Owner / editorial

| Feature | What it does |
|---------|----------------|
| **Auto excerpt** | Fills empty excerpt from first 1–5 sentences on save |
| **Submission checks** | Blocks banned words and too many links |

## Reader / frontend

| Feature | Where |
|---------|--------|
| **Story at a glance** | Single post — quick summary + read time |
| **Key points** | Bullet list from H2/H3 headings |
| **Table of contents** | Jump links when 3+ headings |
| **Smart related** | Better related posts on single article |
| **Trending Now** | Homepage block by view count |
| **Recommended for you** | Homepage for logged-in users |

## Email

**Weekly digest** — plain-text list of last week’s posts. Sent to premium members, or administrators if none.

Configure day/hour under Smart Tools settings.

## Privacy

All processing uses PHP on your WordPress server. No third-party AI services.
